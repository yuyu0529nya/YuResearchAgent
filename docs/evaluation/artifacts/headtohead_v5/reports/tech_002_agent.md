# AI 芯片市场格局分析：训练与推理场景竞争力对比（截至 2026-08）

## 一、市场格局概览

全球 AI 芯片市场正经历结构性转折：推理需求快速超越训练，推理芯片市场规模已达训练市场的约 3 倍；与此同时，中国市场在美国出口管制与国产替代的双重作用下加速重构。据 TrendForce 预测，NVIDIA 与 AMD 在华 AI 服务器芯片合计份额将从 2025 年的 34% 降至 2026 年的约 21%，国产芯片（华为昇腾、寒武纪等）份额升至约 56%，叠加互联网大厂自研 ASIC（约 23%），国产算力已占中国市场近八成；而四年前 NVIDIA 在华份额曾高达约 95% [4]。IDC 数据显示，2025 年中国市场 AI 加速卡出货量约 400 万张，其中 NVIDIA 约 220 万张（份额约 55%，仍居首位但持续收窄），AMD 约 16 万张（约 4%），中国厂商合计约 165 万张（约 41%）[1]。

## 三、训练场景分析

**NVIDIA 的统治地位未被撼动。** 其最新路线图已推进至 Blackwell Ultra GB300 NVL72 与下一代 Vera Rubin 平台，官方宣称在 DeepSeek-V3 671B 预训练中达到 1,648 TFLOPs/GPU 的纪录（厂商自报数据，非第三方实测）[5]。CUDA + NVLink 的软硬件壁垒使其在全球高端训练市场占据 80% 以上份额，万卡级集群的稳定性仍是竞争对手难以企及的护城河。

**AMD 是唯一规模化的西方挑战者，但"在场而未领先"。** MI300X（192GB HBM3）及 MI400 系列训练性能约达 NVIDIA 同代的 85%，价格低 25–30%；ROCm 7 与 CUDA 的差距明显缩小，但大规模集群训练案例仍然稀少。

**Intel 已基本边缘化。** Gaudi 3 强调性价比与以太网互联，但训练市场份额仅 1–3%，生态与产品线动荡使其退出一线竞争。

**华为昇腾是中国训练市场的政策+生态双轮驱动主力。** 昇腾 910C 已支撑万亿参数级训练（DeepSeek V4 全程基于昇腾训练的报道见 2026-04），CANN/MindSpore 全栈生态为国产最完善；但需注意曾有国产大模型在试用昇腾训练后回流 NVIDIA 的案例，说明超大规模集群训练稳定性仍有差距，且先进制程产能受制裁约束。

**寒武纪处于训练第二梯队。** 思元590 纸面 TPP 接近 A100、略高于 H20，八卡服务器售价低于 100 万元（昇腾约 140 万元），价格竞争力强；但实际性能受软件工具链限制，适配需数周至数月 [3]。

## 四、推理场景分析

推理对 CUDA 生态粘性低、替代门槛低，是竞争最激烈、国产突破最快的战场。

- **NVIDIA** 凭 TensorRT-LLM 与 vLLM 的软件成熟度保持推理性能领先 [2]，但在华受 H20/H200 管制影响持续失血。
- **AMD** 凭借大 HBM 显存在长上下文、高并发推理中具明显性价比——MI400 内存带宽对标 B200（4 TB/s），单卡价格低约 15–25%，对大规模推理集群 TCO 影响显著 [2]。
- **华为昇腾**是国产推理事实标准：DeepSeek 早期即采用"训练用 NVIDIA、推理用昇腾"的折中方案，目前昇腾已完成 DeepSeek 全系模型适配。
- **寒武纪**以推理见长：已基于 vLLM 完成 DeepSeek-V4（285B/1.6T）Day 0 适配并开源，并适配 GLM、Qwen、Kimi、MiniMax 等主流国产模型。财务上寒武纪 2025H1 营收 28.9 亿元（同比 +4347.8%）、净利润 10.4 亿元首次扭亏，2026Q1 营收进一步增至 28.85 亿元（+159.6%）[3]。
- **Intel** 仅在边缘与企业轻量推理保留有限空间。

## 五、关键趋势与含义

1. **"国模国芯"协同取代被动迁移。** DeepSeek-V4 发布时 8 家国产芯片厂商实现 Day 0 适配，跨芯片适配时间从数周缩短至数天，开发者切换芯片的成本大幅下降，生态壁垒随之松动 [1]。
2. **国产替代从"备选项"升级为"必选项"。** 出口管制使 NVIDIA 在华重要性系统性减弱；TrendForce 预计 2026 年中国本土高阶 AI 芯片需求同比增长超 60%，国产份额近 80% 的跃升主要发生在推理与互联网自研场景 [4]。
3. **风险点**：昇腾与寒武纪均受制于中芯国际先进制程产能；昇腾 910B/C 各版本算力参数缺乏官方统一口径；各机构对中国市场份额的统计口径差异较大（时间点不同可部分解释 2024 年寒武纪 1% 与 2026 年国产合计 56% 的差异），全球训练/推理芯片精确出货量亦无权威披露。

**结论**：训练端 NVIDIA 全球垄断延续，AMD 是唯一规模化西方替代者，Intel 边缘化，昇腾在中国政策庇护下快速补位；推理端替代加速，AMD 以性价比抢全球份额，昇腾+寒武纪在中国形成结构性优势，市场呈现"全球一超、中国多元"的分化格局。
