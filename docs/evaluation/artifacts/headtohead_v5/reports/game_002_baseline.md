# 中国游戏出海研究报告：《原神》《PUBG Mobile》《黑神话：悟空》

## 一、研究背景

中国游戏出海已从"边缘尝试"演变为行业核心增长引擎。据公开行业数据（中国音数协游戏工委《中国游戏产业报告》），中国自主研发游戏海外市场销售收入在2021年前后达到约180亿美元规模，此后在高位波动。三款代表性产品——《原神》（米哈游，2020年9月28日全球同步发行）、《PUBG Mobile》（腾讯/光子工作室群，2018年3月发行）、《黑神话：悟空》（游戏科学，2024年8月20日发售）——分别代表三种迥异的全球化路径。

---

## 二、三款产品的全球化策略对比

### 2.1 《原神》：GaaS + 全球同步 + 多平台一体化

| 维度 | 策略 |
|---|---|
| 商业模式 | 免费游玩 + 抽卡（gacha）内购，持续运营（GaaS） |
| 发行策略 | 2020年9月28日全球同步上线（移动端/PC/PS4），后扩展至PS5、Xbox（2024年11月） |
| 技术策略 | 跨平台数据互通，约6周一个大版本的稳定内容更新节奏 |
| 营销 | 高强度本地化社媒运营、动画短片、线下音乐会、与餐饮/旅游品牌联动 |
| 收入结构 | 海外收入占比长期较高（据Sensor Tower等第三方估计，海外市场贡献常过半） |

**核心洞察**：《原神》证明了中国厂商能以"内容品质对标主机大作 + F2P长线运营"的组合打入欧美日韩核心市场，打破"国产游戏=低质手游"的刻板印象。

### 2.2 《PUBG Mobile》：IP授权 + 深度本地运营 + 电竞生态

- **模式**：基于韩国Krafton（原Bluehole）PUBG IP授权，腾讯负责开发与发行，规避"纯中国原创IP"的认知门槛。
- **区域定制**：推出轻量版《PUBG Mobile Lite》适配低端机市场；中东版本加入本地服饰与斋月活动；与各地区流行IP联动（如与当地动漫、音乐合作）。
- **电竞**：建立PUBG Mobile Global Championship（PMGC）等全球赛事体系，强化东南亚、南亚、中东用户粘性。
- **挫折与韧性**：2020年9月在印度被禁后，腾讯迅速剥离印度发行权，由Krafton以《Battlegrounds Mobile India》（BGMI，2021年上线）名义回归，2023年5月获准重新上架（附带时长限制等条件）。

### 2.3 《黑神话：悟空》：买断制3A + 文化原生输出

- **策略本质**：不做"文化折中"，以纯正《西游记》叙事 + 顶尖画面（虚幻5引擎）直接面向全球买断制市场。
- **成绩**：发售三天销量超1000万份，首月销量据官方宣布突破2000万份；Steam同时在线峰值超240万，位列历史前列；获2024年TGA最佳动作游戏、玩家之声奖。
- **传播路径**：依靠2020年首支实机预告片的病毒式传播积累全球期待，营销成本远低于手游买量模式。
- **意义**：证明中国单机3A可以直接进入全球核心玩家市场，且"中国神话"本身成为全球卖点而非障碍。

## 三、文化本地化挑战

### 3.1 本地化≠翻译：分层策略

1. **语言层**：《原神》提供十余种语言文本、四国配音（中/英/日/韩），但海外社区仍持续讨论英文本地化"丢失文化细节"的问题（如璃月地区的诗词、典故）。
2. **内容层**：米哈游在须弥（Sumeru）地区融合南亚、中东文化意象，但2022年曾因角色肤色设计引发海外玩家关于文化代表性的争议——显示"借鉴型文化拼盘"的风险。
3. **价值观层**：
   - 《黑神话：悟空》发售后，海外玩家对《西游记》背景知识门槛产生讨论；开发商未做简化，反而带动海外"西游热"。
   - 发行方在直播/评测指南中提及避免某些话题，引发海外媒体关于"输出审查要求"的批评（2024年8月，GamesRadar等报道）。

### 3.2 抽卡文化的接受度差异

- 欧美核心玩家对gacha机制存在抵制情绪（"pay-to-win"批评）；《原神》通过保底机制、内容质量部分化解。
- 日本市场对抽卡接受度高，《原神》《崩坏：星穹铁道》在日表现强劲。

### 3.3 身份与政治敏感性

- 中国厂商在海外市场面临"去中国化"与"中国身份"的两难：腾讯投资Riot、Epic等多采用"隐身股东"策略；《原神》则被部分海外舆论与数据安全、审查议题挂钩。
- 《黑神话》成功让"中国文化"成为正面标签，但这是一次买断制语境下的结果，难以简单复制到长线运营产品。

## 四、各国监管差异

### 4.1 中国本土（出海前提）

- 版号审批制度决定出海产品供给节奏；《原神》《黑神话》均获版号（《黑神话》2024年2月获批）。
- 未成年人防沉迷、内容审查框架使厂商在立项期即内置合规设计，这些设计（如概率公示）反而部分满足了海外监管要求。

### 4.2 主要市场监管对比

| 市场 | 核心监管议题 | 对三款产品的影响 |
|---|---|---|
| **印度** | 国家安全/数据安全（IT法第69A条） | 2020年9月封禁PUBG Mobile等中国背景应用；BGMI模式成为规避样本；《原神》未被封禁但持续受审视 |
| **美国** | 数据安全（CFIUS、各州隐私法）；政治层面对中资应用的审查氛围 | 腾讯所持Riot/Epic股权曾受CFIUS关注（2020年）；2025年前后美方对中资游戏公司审查升温的报道不断 |
| **欧盟** | GDPR数据保护；DSA；《数字市场法》；对比利时/荷兰式"战利品箱=赌博"立法的讨论 | 抽卡概率公示、未成年人保护成为标配；2025年米哈游因抽卡机制在美国遭FTC指控——**2025年1月FTC宣布与米哈游旗下Cognosphere达成2000万美元和解**，涉及向儿童销售战利品箱及COPPA违规，是标志性执法案例 |
| **日本** | 景品表示法约束"コンプガチャ"（complete gacha）；自主规制 | 《原神》合规运营，日本成其重要收入来源 |
| **韩国** | 概率型道具信息公示强制化（2024年3月起实施） | 所有含抽卡游戏须公示概率，米哈游等已合规适配 |
| **中东（沙特、阿联酋等）** | 内容审查（宗教、LGBT元素） | 角色服装、剧情元素需区域性调整；同时中东主权资本（如Savvy Games Group）积极投资游戏业，成为出海新市场 |
| **德国** | USK分级严格，青少年保护法 | 买断制产品如《黑神话》按分级正常发行 |

### 4.3 趋势研判（截至2026年8月）

1. **战利品箱/gacha监管全球化**：韩国概率公示、美国FTC执法、欧盟消费者保护评估共同抬高合规成本。
2. **数据主权**：印度式封禁、美式CFIUS审查、欧盟GDPR构成三套逻辑不同的数据监管体系，厂商被迫采用"区域数据隔离 + 本地实体运营"架构（如米哈游以新加坡Cognosphere/HoYoverse作为海外主体）。
3. **公司架构全球化**：HoYoverse（新加坡）、腾讯Level Infinite（阿姆斯特丹/新加坡）、网易海外工作室布局，均是通过法律实体国际化对冲地缘风险。

## 五、综合评估

| 维度 | 《原神》 | 《PUBG Mobile》 | 《黑神话：悟空》 |
|---|---|---|---|
| 全球化深度 | ★★★★★ | ★★★★★ | ★★★★（买断制单次触达） |
| 文化本地化成熟度 | 高，但有争议事件 | 极高（区域版本定制） | 刻意"不本地化"，以原生性取胜 |
| 监管风险敞口 | 高（gacha+中资+数据） | 高（已被封禁过） | 低（买断制、单机为主） |
| 模式可复制性 | 中（需巨额研发投入） | 低（依赖稀缺IP授权） | 中（国产3A潮已启动，如《影之刃零》等） |

**核心结论**：

1. 中国游戏出海已形成"手游GaaS全球化（米哈游/腾讯）"与"单机3A文化输出（游戏科学）"双轮驱动格局。
2. 文化策略上存在光谱：PUBG Mobile（去文化标识）→ 原神（融合式幻想文化）→ 黑神话（原生中国文化），三者均验证可行，关键在于品质与一致性。
3. 监管是最大不确定性：数据主权、gacha立法、地缘博弈将持续重塑出海架构，"法律实体与数据本地化"已成为标配而非选项。
