# 绿色债券（Green Bond）与可持续发展挂钩债券（SLB）比较研究

## 1. 核心结论

绿色债券与可持续发展挂钩债券（Sustainability-Linked Bond, SLB）的根本差异在于：**绿色债券约束“钱投到哪里”，SLB约束“发行人是否达成可持续结果”**。绿色债券属于“指定募集资金用途”（use-of-proceeds）工具，披露和投资者保护围绕合格项目筛选、资金追踪与影响报告展开；SLB通常是“一般公司用途”债券，其票息、赎回或其他财务条款与预设关键绩效指标（KPI）和可持续绩效目标（SPT）挂钩，披露和保护机制更依赖目标雄心、可核验性、触发条款强度及外部验证。

主要依据为市场自愿性准则：ICMA《Green Bond Principles》（GBP，核心为募集资金用途、项目评估与筛选、资金管理、报告）与《Sustainability-Linked Bond Principles》（SLBP，核心为KPI选择、SPT校准、债券特征、报告、验证）；欧盟另有更严格的《European Green Bonds Regulation》（Regulation (EU) 2023/2631），但其并非普通绿色债券或SLB的全球通用框架。

## 2. 逐项比较

| 维度 | 绿色债券 Green Bond | 可持续发展挂钩债券 SLB |
|---|---|---|
| 基本逻辑 | 资金用途导向：发行债券为合格绿色项目融资或再融资 | 结果/激励导向：债券经济性随发行人可持续绩效变化 |
| 募集资金用途 | 原则上必须分配至合格绿色项目，如可再生能源、能效、清洁交通、污染防治、水和废物管理、绿色建筑、气候适应等 | 通常为一般公司用途，不限定投向绿色资产；可持续承诺体现在KPI/SPT |
| 约束对象 | 资产端/项目组合：项目是否合格、资金是否被追踪分配 | 发行人整体经营结果：如温室气体排放强度、可再生能源占比、范围3排放、回收率、社会指标等 |
| 未达标后果 | 通常不构成违约；风险主要是声誉、认证/第二方意见失效、影响报告不足 | 未达成SPT通常触发票息上调、一次性溢价、赎回价格调整或约定捐赠等；一般也不构成违约 |
| 披露核心 | 资金分配报告、合格项目类别、未分配资金处理、环境影响指标，如减排量、节能量、装机容量 | KPI定义、基线、口径、SPT、目标日期、触发机制、重算/并购调整、年度绩效与外部验证 |
| 投资者保护来源 | 专款专用承诺、项目筛选流程、资金追踪、影响报告、第二方意见、绿色债券框架、必要时Climate Bonds认证 | KPI/SPT的质量与雄心、票息上调等经济惩罚、KPI可审计性、外部验证、限制随意重设目标或改变口径的条款 |
| 主要风险 | “绿色漂洗”：项目边界宽、影响指标薄弱、资金再分配不透明；再融资比例过高；影响非额外性 | “目标漂洗”：KPI不重大、基线有利、目标不具雄心、触发成本过低、通过并购/口径调整稀释目标 |
| 适合发行人 | 有明确绿色资本开支或绿色资产池的主体，如公用事业、交通、绿色建筑、可再生能源 | 缺少大规模可分离绿色项目、但希望承诺整体转型的发行人，如工业、消费品、航空、材料等 |
| 投资者关注点 | 环境影响是否可衡量、资金是否真正流向绿色项目、组合是否与分类法一致 | 惩罚是否足够改变行为、KPI是否覆盖核心排放/外部性、SPT是否与净零路径或行业基准一致 |

## 3. 募集资金用途差异

### 3.1 绿色债券：以“合格项目池”为中心

绿色债券的关键不是发行人的整体 ESG 评级，而是**募集资金是否用于预先定义的绿色项目类别**。ICMA GBP 的四大支柱中，第一项即“Use of Proceeds”，要求募集资金的净额或等价金额用于合格绿色项目，并在发行文件或绿色债券框架中说明项目类别、评估标准、再融资与新融资比例、未分配资金临时管理方式。

典型做法包括：

- 建立绿色债券框架，列明合格项目类别与排除标准；
- 由内部绿色债券委员会或财务/可持续部门联合筛选项目；
- 设置绿色项目台账，追踪募集资金分配；
- 在存续期发布分配报告和影响报告；
- 聘请第二方意见机构、核查机构或认证机构增强可信度。

因此，绿色债券的投资者买到的是一种对**资金投向的合同性/半合同性约束**：发行人仍有偿债义务，但市场期待其把债券净额用于绿色资产。如果发行人将资金挪作一般用途，通常不会立即触发法律违约，却可能损害声誉、失去指数资格、引发投资者问责，极端情况下可能涉及误导性陈述责任。

### 3.2 SLB：以“发行人绩效”为中心

SLB的募集资金通常进入发行人一般资金池，法律上与普通债券接近；其可持续性来自**KPI—SPT—触发机制**链条。根据ICMA SLBP，发行人需要选择对商业模式重大且可衡量的KPI，设定具有雄心的SPT，并说明未达标时的债券财务特征变化，例如票息上调25–50个基点、到期溢价或一次性付款。

这意味着SLB不要求发行人把债券资金专门投入减排项目，而是要求其证明：

- KPI与主业可持续性风险高度相关；
- SPT相对基线、历史趋势和行业路径具有雄心；
- 数据口径、范围、排除项和重算规则清晰；
- 未达标成本足够形成约束；
- 绩效经外部验证。

换言之，绿色债券回答“这笔钱是否绿色”，SLB回答“公司整体是否因债券而更可持续”。

## 4. 信息披露差异

### 4.1 绿色债券披露：分配报告 + 影响报告

绿色债券披露通常分为发行前与发行后：

- **发行前**：绿色债券框架、合格项目类别、项目评估流程、资金管理政策、报告安排、外部评审意见。
- **发行后**：至少定期披露募集资金分配比例、已融资项目清单或组合层面信息、未分配资金余额及临时投向；影响报告可包括预期或实际减排量、可再生能源发电量、能效提升、污水处理量等。

其披露强项是**可追溯性**：投资者可看到资金进入哪些项目类别。但其弱点是影响指标未必统一，项目层面数据可能以“预期影响”代替“实际影响”，且组合层面的加总、避免重复计算和基线选择存在方法差异。

### 4.2 SLB披露：KPI/SPT定义 + 触发条款 + 验证

SLB披露更类似“对赌条款说明书”，重点是：

- KPI为何重大、是否覆盖核心业务外部性；
- 基线年份、历史数据、边界、温室气体核算范围；
- SPT是否领先于“一切照常”情景；
- 是否存在中间观察日与最终目标日；
- 未达标的票息上调幅度、计算方法与上限；
- 并购、资产剥离、会计政策变化、方法学更新时如何重算；
- 是否允许发行人修改KPI/SPT，以及修改需何种同意程序；
- 年度绩效报告与外部验证安排。

SLB披露的关键不是“资金去了哪里”，而是**目标是否难到足以改变行为，且条款是否防止发行人轻易脱身**。如果KPI选择边缘指标、SPT低于行业自然下降趋势，或触发成本相对于融资节约微不足道，SLB可能更像低成本的可持续标签。

## 5. 投资者保护差异

### 5.1 绿色债券：保护集中在资产端与透明度

绿色债券投资者保护主要来自：

1. **用途限定**：通过发行文件、绿色债券框架和募集资金管理承诺约束投向；
2. **流程治理**：项目筛选、环境效益评估、排除标准；
3. **资金追踪**：绿色项目台账、专户或内部记账、未分配资金管理；
4. **外部背书**：第二方意见、发行后核查、绿色债券认证；
5. **持续问责**：年度分配/影响报告、投资者沟通、指数与授权约束。

但其保护上限明显：若项目最终环境效益不佳，或影响报告弱于预期，投资者通常没有票息补偿。绿色债券的“保护”更偏向**信息权和声誉约束**，而非财务补偿。

### 5.2 SLB：保护集中在激励兼容与惩罚条款

SLB投资者保护主要来自：

1. **经济触发器**：未达SPT导致票息上调、赎回溢价或付款；
2. **目标质量要求**：KPI须重大、可测量、可外部验证；
3. **反稀释条款**：限制通过重设基线、改变口径、并购处理来规避未达标；
4. **验证机制**：要求发行前评审与目标日外部验证；
5. **文件锁定**：将KPI/SPT、触发事件、fallback与重算规则写入债券条款，而非仅放在可持续报告中。

SLB的风险在于保护机制可能“形式大于实质”：票息上调可能太小，目标日期可能太远，观察期可能避开信用恶化时期，KPI可能被发行人通过边界调整实现“技术性达标”。此外，未达SPT通常不等于违约，因此持有人不能像发生债务违约那样加速清偿；补偿仅来自约定可持续性条款。

### 5.3 关键保护差异总结

- 绿色债券失败更多是**环境完整性失败**：钱没有产生足够绿色效益；
- SLB失败更多是**激励设计失败**：目标不雄心或惩罚不足，发行人仍可低成本使用标签；
- 两者一般都不因可持续表现差而触发传统违约；真正硬保护取决于是否把可持续承诺写入契约性条款、是否设置可执行补偿、是否有独立验证与争议处理机制。

## 6. 实务评估清单

### 绿色债券应重点审查

- 合格项目类别是否清晰，是否排除高碳锁定资产；
- 新融资与再融资比例；
- 资金分配是否逐项目或至少逐类别追踪；
- 影响指标是否区分预期与实际、毛减排与净减排；
- 是否有发行后核查或认证；
- 是否与发行人整体气候战略一致，避免“绿色项目、棕色母公司”。

### SLB应重点审查

- KPI是否覆盖发行人最重要可持续外部性，尤其范围1/2及相关范围3排放；
- SPT是否超越历史趋势、监管要求和行业自然改进；
- 是否设中间观察日，避免“期末一次性冲刺”；
- 票息上调是否足以抵销可持续标签带来的融资利差收益；
- 并购、剥离、核算方法变化时的重算规则是否中性；
- KPI/SPT变更是否需要持有人同意或独立意见；
- 外部验证是否覆盖目标达成日，而非仅覆盖框架设计。

---

## 7. 结论

绿色债券更适合追求**可识别、可追踪环境影响**的投资者，其优势在资金用途清晰、项目披露成熟；弱点是影响额外性和资金挪用通常不带来财务补偿。SLB更适合推动发行人**整体转型**的场景，尤其当企业缺乏足够绿色资产池时；但其可信度高度依赖KPI重大性、SPT雄心、触发强度和防止目标稀释的法律设计。对投资者而言，绿色债券要防“项目漂绿”，SLB要防“目标漂绿”；两者都应把披露承诺尽量转化为可验证、可执行、不可轻易重算的债券条款。

**参考框架**：ICMA Green Bond Principles；ICMA Sustainability-Linked Bond Principles；Climate Bonds Initiative Standard；Regulation (EU) 2023/2631 作为欧洲绿色债券更高披露与用途标准的参照。
