# 数字疗法（DTx）在慢病管理中的临床证据、监管路径与商业化挑战评估

**研究基准日期：2026-08-14**

## 一、核心结论与三病种对比

数字疗法（Digital Therapeutics, DTx）在糖尿病、高血压、抑郁症三个慢病领域已积累不同程度的临床证据和监管突破，但"证据—监管—支付—收入"的传导链条尚未完全打通。三病种的综合对比如下：

| 维度 | 糖尿病 | 高血压 | 抑郁症 |
|---|---|---|---|
| 代表产品 | BlueStar（Welldoc，美国） | CureApp HT（日本） | reSET 系列、Rejoyn（美国） |
| 关键证据 | RCT显示HbA1c显著下降 | HERB-DH1试验：24h动态血压显著下降 | 数字CBT类RCT，效应量中等 |
| 监管进展 | 2010年FDA批准（首个处方DTx之一）[4] | 2020年日本全球首个高血压DTx获批；美国尚无 | 2017年reSET首个FDA De Novo处方DTx [4]；2024年首个MDD处方DTx Rejoyn获批 |
| 支付现状 | 报销零散，支付方对增量价值存疑 | 日本2022年纳入国家医保（唯一标杆） | 美国CMS 2025年起设DMHT报销代码 [3]；德国DiGA可报销 |
| 综合前景 | ★★★（证据强、支付转化难） | ★★（降幅小、付费意愿弱） | ★★★★（监管先行、需求刚性） |

## 二、临床证据：病种间的不均衡积累

**糖尿病**是证据积累最早的领域。Welldoc的BlueStar于2010年基于优效性试验数据获FDA批准，成为最早获批的处方DTx之一 [4]；其随机对照试验（Quinn et al., 2011/2013）显示移动糖尿病管理系统可显著降低糖化血红蛋白（HbA1c），行业报道降幅约1.2–1.9个百分点。需注意该具体降幅数字来自行业媒体报道，属厂商相关披露，未在本次检索中取得原始论文全文验证。

**高血压**的关键证据来自日本CureApp的HERB-DH1关键性试验，该多中心RCT评估了DTx系统在原发性高血压管理中的疗效，主要终点为24小时动态血压 [1]。产品于2020年获批，2022年纳入日本医保，是目前全球唯一跑通"监管批准+国家医保报销"闭环的慢病DTx样板；但血压绝对降幅仅约2–5 mmHg量级，增量价值有限。

**抑郁症**方面，数字认知行为疗法（CBT）的RCT证据相对扎实。监管里程碑密集：2017年Pear Therapeutics的reSET成为首个以De Novo路径获FDA批准的处方DTx（物质使用障碍）[4]；2024年FDA批准Rejoyn（Otsuka × Click Therapeutics）用于重度抑郁障碍患者的辅助治疗，成为首个针对MDD的处方DTx。此外，Somryst（数字CBT-I）作为失眠处方DTx已有安全性与有效性综述文献 [1]。

**共同的证据短板**：多数DTx试验样本量小、随访期短（数周至6个月），缺乏心血管事件、死亡率等硬终点和长期卫生经济学数据，这直接制约了支付方的买单意愿。国内方面，虽有企业启动妊娠糖尿病等DTx临床试验入组，但尚无公开发表的注册级RCT结果，中国临床证据的透明度明显不足。

## 三、监管路径：三大市场的分化格局

**美国FDA**将DTx归入独立医疗软件（SaMD），按风险走510(k)、De Novo或PMA路径。2010年BlueStar获批与2017年reSET的De Novo批准确立了"软件可作为处方治疗"的监管先例 [4]，此后ADHD（EndeavorRx）、慢性失眠（Somryst）、MDD（Rejoyn）等相继获批，精神类已成为FDA获批DTx数量最多的类别。

**中国NMPA**按医疗器械三类体系管理，此前DTx多以二类证获批。2023年3月，NMPA标管中心在分类界定结果汇总中，将"认知功能障碍评估与治疗软件"与"胰岛素计算软件"——分别对应精神心理和糖尿病管理两类典型DTx——界定为**第三类医疗器械**，原因是含人工智能辅助决策或药物剂量计算功能的产品按决策支持软件管理 [2]。这意味着这两类DTx的注册门槛（资金、时间、临床要求）显著抬升；但分类界定具"一事一议"性质，专门的数字疗法分类界定指导原则截至本次检索未见正式发布，政策走向仍存不确定性。

**欧盟**依据MDR (EU) 2017/745的Rule 11，提供诊疗决策信息的软件多被归为IIa类及以上，较旧指令明显趋严。德国的**DiGA快速通道**允许I类和IIa类数字健康应用经BfArM快速评估后进入医保报销目录，是目前欧洲乃至全球最具参考价值的DTx报销制度设计，精神类应用在其中占比最高。

## 四、商业化挑战：获批不等于成功

Pear Therapeutics的兴衰是最典型的反面教材：该公司2021年底以SPAC上市、估值约16亿美元，拥有reSET、reSET-O、Somryst三款FDA获批产品，却于2023年4月申请破产保护，资产最终仅售约600万美元。失败根源在于三点：一是**报销缺口**，商业保险普遍要求事前授权和传统疗法失败证明，谈判耗时且常仅获部分覆盖；二是**医生工作流不兼容**，DTx所需的参与度追踪无法嵌入标准门诊模式，且多数平台不能与电子病历系统对接；三是**真实世界患者依从性远低于临床试验水平**，3–6个月后使用率骤降，长期效果与复购均受损。Pear选择成瘾这一难治适应症并定高价的策略，也被同业认为是战略性失误——对糖尿病、高血压等更常见、价值主张更清晰的慢病场景反而是启示。

**支付端**的最新进展喜忧参半。美国CMS自2025年1月起设立数字精神健康治疗（DMHT）专门报销代码，但2025年上半年医生端实际采纳率很低：同一DTx干预在不同Medicare行政承包商辖区获得不同的覆盖决定和支付费率，造成收入规划的高度不确定性 [3]。这表明**报销代码的存在本身不足以驱动采纳**，支付落地的"最后一公里"依赖执行层面的统一。中国市场的支付通道则基本空白，基本医保未纳入DTx，企业主要依靠B2B模式（药企合作、商保、医院采购）维持，2023年后行业融资明显收缩，商业模式尚待标杆项目验证。

**三种商业模式各有硬伤**：处方模式（PDTx）证据与可信度最强，但监管投入大、报销复杂（Pear即败于此）；B2B模式现金流较快但销售周期长、需向雇主与保险方证明ROI；B2C模式上市快却临床可信度弱、用户留存率低。高血压DTx因疾病无症状、患者主动付费意愿最低，几乎只能依赖医保渠道，C端不可行——这也解释了为何其商业化样板仅出现在医保制度配合的日本。

## 五、分析与展望

三病种的商业化可行性排序为：**抑郁症 > 糖尿病 > 高血压**。抑郁症DTx胜在行为干预天然适配、精神科医生短缺放大替代需求、且监管路径（含2024年Rejoyn获批）已经打通；糖尿病DTx临床证据最强，但在GLP-1等强效药物时代，支付方对DTx边际获益的态度趋于保守，"证据—支付"转化率低；高血压DTx受限于效应幅度小和付费场景窄。

行业的共同出路包括：补齐长期硬终点与成本效益证据以支撑支付决策；推动DTx专属报销编码的落地与执行统一（美国DMHT代码在2026年后的采纳效果尚待观察）；以"药物联合辅助"而非"替代治疗"的定位降低证据门槛。中国短期内将以"医疗器械审批+医院/商保渠道"渐进推进，全国性医保覆盖预计仍需数年的本土证据积累。需要说明的是，本报告部分临床效应量数字依赖行业媒体转述，原始试验全文及中国支付端最新数据存在检索缺口，相关结论应作相应保留。
